# HeartGuard
HeartGuard – Heart Disease Prediction Using Machine Learning

Project Overview
HeartGuard is a machine learning project that uses the Heart Disease dataset from the UCI Machine Learning Repository. It analyzes patient health information to predict the possibility of heart disease using machine learning techniques.

Objective
- To analyze heart disease data and identify important health-related patterns.
- To build a machine learning model that predicts the possibility of heart disease.

Dataset
- Source: UCI Machine Learning Repository
- Dataset: Heart Disease Dataset
- Contains patient health-related information and heart disease records.

Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

Project Workflow
1. Import required libraries.
2. Load the dataset.
3. Explore and understand the data.
4. Clean and preprocess the data.
5. Perform data analysis and visualization.
6. Train a machine learning model.
7. Evaluate the model performance.
8. Predict heart disease.
